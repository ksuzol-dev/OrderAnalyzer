# Data Model

## 核心分析字段

| 标准字段 | 说明 | 新业务线映射 |
| --- | --- | --- |
| 订单编号 | 订单去重统计使用；缺失时自动生成内部行号 | 可缺省 |
| SKU | 商品 / 权益名称 | VIP 名称 |
| 支付状态 | 判断是否计入分析 | 支付状态 |
| 支付金额 | 收入和客单价 | 开通价格 |
| 支付完成时间 | 趋势和日期聚合 | 开通时间 |

## V0.3.1 新增标准字段

| 标准字段 | 说明 | 新业务线映射 |
| --- | --- | --- |
| source_platform | 来源平台 | 来源平台 |
| pay_type | 开通方式 | 开通方式 |
| vip_id | VIP ID | VIP ID |
| vip_name | VIP 名称 | VIP 名称 |
| vip_type | VIP 类型 | VIP 类型 |

## 支付成功规则

- `支付状态 = 已支付`
- 兼容旧数据中的 `支付成功`
