# V0.3 Foundation

V0.3 将 V0.2 的单文件应用拆分为更稳定的分析平台结构，并保留本地运行、只分析支付成功订单、不提交真实订单数据的原则。

## 本阶段范围

- Dashboard：首页展示今日订单、今日收入、客单价和环比。
- 趋势分析：趋势图下方增加每日数据表。
- SKU 分析：增加订单数占比、收入占比和 TOP10 明细。
- 用户分析：预留模块入口，不实现完整生命周期分析。
- 数据检查：显示字段、订单数、支付成功数和识别字段。

## 开发模式

- `main` 保持稳定版本。
- `develop` 用于 V0.3 之后的新功能开发。
- CSV、Excel、zip、真实订单数据不进入 Git。
